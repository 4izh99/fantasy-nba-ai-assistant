# Fantasy NBA AI Assistant

A personal, non-commercial AI-powered analytics project for Yahoo Fantasy Basketball.

## Project Overview

This application is being developed to help a single user analyze a private 12-team Yahoo Fantasy Basketball league.

## Planned Features

- Retrieve current team rosters and league settings.
- Analyze weekly head-to-head matchups.
- Compare player statistics and fantasy performance.
- Evaluate potential trades between league participants.
- Identify valuable free agents and waiver-wire opportunities.
- Provide AI-assisted roster optimization recommendations.

## Technical Approach

The application is planned to use the official Yahoo Fantasy Sports API with read-only OAuth 2.0 access.

A private backend service will connect Yahoo Fantasy data to a ChatGPT-based assistant for analysis and recommendations.

## Project Status

Early development — Yahoo Fantasy Sports API access pending approval.

## Usage

Personal, non-commercial use only. One authorized user. No public service or monetization.
